
# 🌱 Crop Prediction App

A machine learning-based web application that predicts the most suitable crop based on agricultural and environmental parameters.

## 📖 About the Project

The Crop Prediction App helps users identify suitable crops based on input parameters such as soil nutrients and environmental conditions. It uses a machine learning model to generate crop predictions through a simple web interface.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Arpa84/Crop_Prediction_App.git
```

### 2. Navigate to the Project Folder

```bash
cd Crop_Prediction_App
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Your Browser

Visit the following URL:

http://127.0.0.1:5000

## 📋 Requirements

Make sure Python is installed on your computer and the required dependencies are listed in `requirements.txt`.
