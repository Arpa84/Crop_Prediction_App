# 🌱 Crop Prediction App

A machine learning web application that predicts suitable crops based on agricultural parameters.

## 🛠️ Technologies Used

- Python
- Flask
- Machine Learning
- Scikit-learn
- HTML and CSS

## ⚙️ How to Run
```
pip install -r requirements.txt
python app.py
```

Open in your browser: [http://127.0.0.1:5000](http://127.0.0.1:5000)
